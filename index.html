This explains what data Saturn collects and why. Since this is a friends-only bot, data handling is minimal.

1. What Data Saturn Collects

Data Type Examples Stored? Location
Discord User ID 123456789012345678 (example — not real) Yes (temporary) RAM (lost on restart)
Auto-response toggle /torespond preference Yes (until restart) RAM
Conversation history Last 10–20 messages you send to Saturn Yes (temporary) RAM (lost on restart)

  • Prevent spam (cooldown system)

3. Third-Party Services (Your Data is Sent Here)

  • Groq Inc. (AI text generation) – https://groq.com/privacy-policy/

Your Discord User ID may be included in API calls for debugging purposes. No full conversation history is shared — only the immediate prompt needed to generate a response.

4. Data Retention

  • RAM-based data (conversation history, toggles, cooldowns): Lost when Saturn restarts.
  • No permanent storage – Saturn does not save messages or user data to disk except for basic runtime variables.
